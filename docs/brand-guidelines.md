# Luné 品牌規範 v1.0

最後更新：2026-11-12。介面的 token 與元件樣式在 `web/src/app/globals.css`，向量檔在 [`docs/brand/`](brand/)。視覺提案（含沒採用的方案）在 `design/proposals.html`、`design/logo-proposals.html`。

## 速查

| 項目 | 內容 |
| --- | --- |
| 名稱 | **Luné**（é 要保留重音；不寫成 Lune、LUNE） |
| 標語 | 輕輕記下，慢慢看懂自己 |
| 標誌 | C「週期軌道」：傾斜的手繪橢圓＋玫瑰光球（今天）＋檸檬薄荷小光球（下一次） |
| 主色 | 霧藍 `#477A92`（文字底色下限）、深霧藍 `#3F6F86` |
| 品牌色 | 玫瑰光球（經期、今天） |
| 字型 | 英數 Outfit 200／300／400；中文 Noto Sans TC 400／500／700 |
| 語氣 | 溫柔但清楚、不診斷不說教、誠實面對不確定 |

## 1. 品牌核心

- **為什麼存在**：讓記錄生理週期變得容易，不讓使用者為了記錄而增加負擔。
- **我們是什麼**：手機優先的生理期與身體狀態紀錄工具。首頁就能完成記錄，日曆看懂過去，預測只當參考。
- **主要訊息**：點幾下就能記下今天，紀錄越多，越看得懂自己的週期。
- **我們不是什麼**：不是醫療診斷工具，也不是避孕工具；不做社群，不賣資料。

| 訊息 | 對應的需求 | 依據 |
| --- | --- | --- |
| 點幾下就記好 | 不想花時間 | 首頁三顆按鈕；每日紀錄只有日期必填，其他都可以不填 |
| 實際和預測分得清楚 | 不想被誤導 | 實際＝實心光球、預測＝虛線圈；預測一律給日期區間並標示「預測」 |
| 你的資料只屬於你 | 健康資料很私密 | 資料庫逐列隔離；不傳給 AI 或第三方；可以匯出、可以刪除帳號 |

## 2. 語氣

### 我們是

| 特質 | 意思 | 這樣寫 | 不這樣寫 |
| --- | --- | --- | --- |
| 溫柔但清楚 | 口吻放輕，資訊不打折 | 「經期已經 12 天，是不是忘了按結束？」 | 「錯誤：經期超過上限」 |
| 不診斷、不說教 | 只描述紀錄，不判斷身體 | 「最近幾次週期長度差距較大，預測僅供參考」 | 「你的週期不規律，可能有健康問題」 |
| 誠實面對不確定 | 估算就說是估算，資料不夠就說不夠 | 「累積更多紀錄後即可預測」 | 「下次經期：11 月 26 日」（沒有區間、沒有標示預測） |
| 簡短、可行動 | 一句說清楚，再告訴對方下一步 | 「已有進行中的經期，請先結束或編輯那一筆」 | 「操作失敗」 |

### 不同情境的語氣

| 情境 | 語氣 | 範例 |
| --- | --- | --- |
| 儲存成功 | 簡短確認，帶日期 | 「已儲存 11/11 的紀錄」 |
| 欄位錯誤 | 說哪裡不對、要怎麼改，放在欄位旁邊 | 「結束日期不能早於開始日期」 |
| 系統錯誤 | 不推給使用者，給下一步 | 「系統發生錯誤，請稍後再試」 |
| 空狀態 | 鼓勵、說明第一步 | 「還沒有身體紀錄。按「記錄今天」，點幾下就好。」 |
| 健康提醒 | 一般性建議，不下結論 | 「若出血量、疼痛或週期變化讓你擔心，建議諮詢醫療專業人員。」 |
| 刪除確認 | 直接說後果 | 「確定刪除？無法復原」 |
| 隱私權政策、條款 | 較正式，但仍用白話 | 「本服務不販售資料、不投放廣告」 |

### 用詞

- 稱呼對方用「**你**」，不用「您」。
- **紀錄**是名詞（「每日紀錄」「編輯紀錄」），**記錄**是動詞（「記錄今天」「不能記錄未來的日期」）。
- **經期**用在資訊與統計（「經期第 3 天」「平均經期」）；**生理期**只用在口語的動作按鈕（「開始生理期」「結束生理期」）。
- **週期**：兩次經期開始日之間的天數；不寫「月經週期」。
- **預測**標在畫面上；**估算**用在說明文字（「預測依過去紀錄估算」）。
- **Profile** 保留英文，不翻成「檔案」或「成員」。
- 避免醫療化或評價的字眼：異常、病、正常／不正常、應該。

### 格式

- 標點一律全形（，。、：；「」）；中英文、中文與數字之間加一個半形空格：「週期第 13 天」「Profile 管理」。
- 日期：短格式 `11/11`；完整格式「11 月 11 日（週三）」；區間用 en dash：「11/24–11/28」。
- 數字與單位之間空一格：「29 天」「500 個字」。

## 3. 標誌

### 構成

- **軌道**：傾斜 −22° 的手繪感橢圓，代表一整個週期。深色底用白色，淺色底用深色 `#2B3A44`。
- **玫瑰光球**：今天在週期裡的位置，永遠是玫瑰漸層。
- **檸檬薄荷小光球**：下一次。
- **字標**：Outfit 300，字距 0.16em；向量版已轉成路徑（`docs/brand/wordmark-*.svg`），不依賴字型。

### 檔案

| 檔案 | 用途 |
| --- | --- |
| `mark-on-dark.svg`／`mark-on-light.svg` | 只有標誌（透明底） |
| `lockup-on-dark.svg`／`lockup-on-light.svg` | 組合標誌（標誌＋字標，主要版本） |
| `wordmark-on-dark.svg`／`wordmark-on-light.svg` | 只有字標 |
| `app-icon.svg` | App 圖示（滿版方形，系統會自己裁圓角） |
| `app-icon-rounded.svg` | 圓角版（文件、簡報用） |
| `app-icon-maskable.svg` | Android 可裁切成圓形的版本（標誌縮在中間 72%） |
| `favicon.svg` | 16–48px 專用：線條加粗、光球放大、沒有微光 |
| `avatar.svg`／`avatar-1024.png` | 大頭貼（GitHub、Vercel、社群帳號）：標誌縮在中間安全區，裁成圓形也安全；線寬介於一般版與加粗版之間，縮到 24px 仍看得到軌道 |

網站實際使用的圖示（`web/src/app/icon.svg`、`favicon.ico`、`apple-icon.png`、`opengraph-image.png`、`web/public/icons/*`）全部由 `cd web && node scripts/build-brand.mjs` 產生。標誌的幾何只定義在這支腳本和 `web/src/components/ui/brand-mark.tsx`，兩邊要一起改。字標路徑用 `python scripts/wordmark-path.py <Outfit[wght].ttf>` 重新產生。

### 使用規則

- **留白**：四周至少留玫瑰光球的直徑。
- **最小尺寸**：
  - 標誌小於 40px 一律用加粗版（`favicon.svg`；元件 `BrandMark` 會自動切換）；
  - 組合標誌寬度至少 96px。
- **背景**：
  - 深色底：霧藍、深霧藍、照片暗部，用白色軌道；
  - 淺色底：奶油白 `#F7F4EF`、白，用深色軌道；
  - 不要放在中間調的花色背景上。
- **不要**：
  - 改變軌道角度、壓扁或拉長；
  - 把玫瑰光球換成其他顏色；
  - 拿掉小光球；
  - 加外框或陰影；
  - 字標改用其他字型或拿掉 é 的重音。

## 4. 色彩

所有顏色都用 `globals.css` 的 token 或 class，元件裡不寫死色碼。下表的對比是**實際畫面量測**的數字，量的是疊上顆粒雜訊之後的底色。

| 名稱 | 色碼 | 用途 | 白字對比 |
| --- | --- | --- | --- |
| 霧藍 `--color-sky` | `#477A92` | 文字底色的下限 | 4.7:1 |
| 深霧藍 `--color-sky-deep` | `#3F6F86` | 畫面下方、深色面板 | 5.5:1 |
| 背景漸層（實際繪製） | `#40728A → #3A687E` | `body` 底層；疊上雜訊後約等於上面兩色 | 實測 4.8–5.5:1 |
| 霧白 `--color-mist` | `#96C0D2` | 只用在裝飾（右上角霧氣） | 不放文字 |
| 光球深字 `--color-orb-ink` | `#2B2A33` | 放在淺色光球上的文字 | 在玫瑰光球上 6.0:1 |
| 淺底深字 | `#2B3A44` | 淺色背景上的文字與標誌 | 在奶油白上 10.7:1 |
| 淡粉 `--color-blush` | `#F6B7C4` | 目前所在頁的光點 | 不放文字 |
| 圖表資料 `--color-chart` | `#F6B7C4` | 分析頁的折線、標記點、長條（單一系列） | 對玻璃面板底色 3:1 以上（圖形的要求） |
| 提示紅 `--color-alert` | `#FFE3E8`（底 `#6E1E37` 45%） | 欄位錯誤 | 9:1 |

**光球色票**：
- 玫瑰（經期、今天、品牌色）、薰衣草、蜜桃、鼠尾草、天空、沙色，class 是 `orb-*`；
- 也是 Profile 的代表色；
- 實際經期在月曆上**一律用玫瑰**，不跟著 Profile 換色。

**規則**：
- 白字的底色畫出來不能淺於 `#477A92`；
- 玻璃面板用偏深的半透明（`.glass`），不用白色半透明，因為白色會把底色提亮；
- 新增會讓背景變亮的效果（光暈、霧氣、填色）後，要重新量對比（量法見 README）。

## 5. 字型

| 用途 | 字型 | 字重 | 範例 |
| --- | --- | --- | --- |
| 英文標題 | Outfit | 300，字距 0.2em，全大寫 | CALENDAR、INSIGHTS |
| 大數字 | Outfit | 200 | 首頁的週期天數、分析頁的統計 |
| 日期、數字 | Outfit | 400 | 11/11、2026 . 11 |
| 中文內文 | Noto Sans TC | 400／500 | 13–16px，字距 0.04–0.14em |
| 中文標題 | Noto Sans TC | 500 | 頁面標題、面板標題 |

- 英文標題只是裝飾（`aria-hidden`），旁邊一定要有中文標題當真正的 `h1`／`h2`。
- 內文不小於 13px；說明文字最小 11px，而且只用在免責聲明這類次要資訊。
- 字型自架在 `web/src/app/fonts/`。介面新增中文字後，重跑 `python scripts/subset-font.py noto-sans-tc …`。

## 6. 圖形元素

| 元素 | 意思 | 用法 |
| --- | --- | --- |
| 光球（實心） | 已經發生的事：經期、今天 | 月曆的經期日、首頁主視覺、星座圖 |
| 虛線圈 | 預測、估算 | 月曆的預測經期、星座圖最上面那顆；一定搭配「預測」文字或圖例 |
| 細白線 | 有關聯的資料 | 串起同一次經期的日子、從現在連到下一次 |
| 手繪感橢圓 | 主要動作 | 開始／結束生理期、記錄今天、儲存 |
| 玻璃面板 | 內容群組 | 當日詳情、統計、設定區塊；底部面板用更深的版本 |
| 點狀底線 | 可能開始的日子 | 月曆上預測區間但不在預估經期內的日子 |

- **不只靠顏色**：
  - 每種狀態都要有形狀上的差別（實心、虛線、細圈、圓點）；
  - 月曆附圖例；
  - 每一格的 `aria-label` 都寫出狀態。
- **動態**：
  - 光球緩慢漂浮（9–13 秒一個循環），面板淡入上浮；
  - 系統開啟「減少動態」時全部停用。

### 圖表

照 dataviz 的規則做，配色用驗證腳本確認，不靠肉眼判斷。

- **單一系列**：不放圖例，標題說明畫的是什麼；文字一律用文字色，不用資料色。
- **線與點**：折線 2px；標記點半徑 4，外面加一圈 2px 的底色外框；被排除的資料（例如沒列入平均的週期）用空心點。
- **長條**：最粗 24px，數值端 4px 圓角、基線端方角，依多寡排序，數值標在條尾。
- **格線**：1px 實線、淡色；參考線（個人平均）在線尾標數字。
- **互動**：滑過或用鍵盤聚焦時顯示讀數；每張圖都有「以表格檢視」。
- **範圍篩選**：放在所有圖表上方同一列，篩選會套用到下面每一張圖。

## 7. 隱私是品牌的一部分

- **通知、分享、網址**：分享預覽圖、網址、錯誤日誌裡都不出現任何健康內容（症狀、經血量、備註）。
- **分享預覽圖**：只放標誌、標語和「生理週期與身體狀態紀錄」。
- **行銷文案**：不用「精準預測」「排卵／避孕」等字眼，預測一律稱為估算。
