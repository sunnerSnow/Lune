兩套方案都從參考網站抓出同一組版面手法，但用法不同。抓出的手法：

  • 霧面底色＋細顆粒雜訊與織紋；上方漸層淡出、帶模糊的頁首
  • 漸層光球（玫瑰粉／檸檬薄荷／薰衣草藍），用細線串成星座
  • 寬字距英文大寫標題，搭配小字中文副標；大而細的數字
  • 手繪感的橢圓外框按鈕（帶微光）、細線圓形箭頭鈕、「—」短線分隔
  • 大圓角玻璃面板（半透明＋背景模糊＋淡白邊框）
  • 「1 / 3」章節編號＋整片漸層網格色塊、左右錯位排列的不規則圓形

畫面用同一份範例資料：今天 11/11（週三），上次經期 10/28–11/1，近 5 次週期 28／30／29／31／28 天，預測下次 11/24–11/28。

A 霧藍星球

照參考網站的世界觀：霧藍底、白字，週期用漂浮的光球呈現，資料之間用細線連起來。

版面手法

  • 首頁主視覺是一顆大光球，裡面放「週期第 N 天」，旁邊的小光球分別是下次預測和上次經期，用細線相連
  • 快速操作是三個互相交疊的手繪橢圓
  • 分析頁把每次經期畫成一顆光球、左右錯位往下排；連線上標出週期天數

元件

  • 表單是玻璃底部面板（34px 圓角）
  • 導覽是浮在底部的玻璃膠囊；目前所在頁用粉色光點標示
  • 日曆：實際經期是實心光球，預測是虛線圈，兩者都有連線把同一次經期串起來

對比與可讀性

  • 參考網站的淺藍 #6FA6BC 配白字對比只有 2.7:1，所以文字區改用 #477A92（4.7:1）
  • 實際經期的日期數字用深色字壓在粉色光球上（約 5.5:1）
  • 狀態不只靠顏色區分：還有實心／虛線圈／細線圈／小圓點，另附圖例

B 奶油章節

規格要的奶油白、深棕灰字；參考網站的「1 / 3 章節＋漸層色塊」用來排首頁，分析頁用錯位排列的不規則圓形。

版面手法

  • 首頁是三段整片漸層：1 / 3 現在（玫瑰）、2 / 3 下一次（薰衣草）、3 / 3 今天（鼠尾草），每段都有大號細數字
  • 快速操作是墨色手繪橢圓，放在第 3 段
  • 分析頁的三個統計數字放在錯位排列的不規則圓形裡，下方是用「—」細線分隔的週期清單

元件

  • 每日紀錄是全螢幕頁，四個段落編號 01–04，用細線分隔
  • 導覽是純文字，中間有圓點分隔；目前所在頁下方有一顆小光球
  • 日曆每週用細線分隔；預測日是虛線圈加斜線（規格要的「淺粉／斜線」）

對比與可讀性

  • 主要文字 #3D3533 在奶油底上 11:1，次要文字 #6E6461 5.4:1
  • 強調色 #A8405F：當文字 5.5:1，上面放白字 5:1
  • 漸層色塊上的字一律用深色，最深的粉色只放在角落

COMMON

  • 兩套都是手機優先；桌面版改成左側導覽，紀錄表單用側邊面板。
  • 經期進行中時，首頁的「開始生理期」會換成「結束生理期」，並顯示經期第幾天。
  • 首頁的 11/24–11/28 是「可能開始的區間」；日曆標的是最可能的 5 天（11/26–11/30，以平均經期 5 天推算）。
  • 動態：光球緩慢漂浮、按鈕按下有微光擴散；系統開啟「減少動態」時全部停用。
  • 字型：英數用 Outfit（跟參考網站同一套），中文用 Noto Sans TC（正式版會自架字型檔）。
  • 深色模式：方案 A 本身就偏深；B 如果要做深色版，之後再補。
